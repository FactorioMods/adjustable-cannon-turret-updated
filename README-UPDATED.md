# Adjustable Cannon Turret: Updated

Adds the configurable cannon turret, with its original item, recipe and technology names.

Requires Factorio 2.1.24 or later. Enable the dependencies listed in the mod manager. This fork keeps the original mod’s content rather than introducing a new balance model.

Existing saves using adjustable_cannon_turret can migrate to this mod identity. Keep a backup when changing a mod set, and disable the original when selecting this fork.

Original mod: [ adjustable_cannon_turret ](https://mods.factorio.com/mod/adjustable_cannon_turret). Original author credits and applicable license notices are retained in the source package.
